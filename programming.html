Programming Skills

研究および大学の講義を通じて、低レイヤーからアプリケーション層まで幅広い開発経験を積んでいます。特に計算機システムの内部構造を理解するためのフルスクラッチ開発に注力してきました。

C 研究・講義実装

用途：次世代ネットワークプロトコルの実装、システムプログラミング

  • 独自ターミナルの作成（約2,000行）: 大学の講義にて、シェル（ターミナル）をC言語でフルスクラッチ開発。プロセス管理（fork/exec）、パイプ処理、リダイレクション、シグナルハンドリング等のシステムコールを深く理解しました。
  • 研究利用: SmartNICやDPDKを用いたパケット処理エンジンの開発において、メモリ管理やポインタ操作を駆使したパフォーマンス最適化を行っています。
Java 講義実装

用途：言語処理系の理解、オブジェクト指向開発

  • コンパイラの作成（約2,000行）: 独自のプログラミング言語をターゲットとしたコンパイラをJavaで実装。字句解析、構文解析、抽象構文木（AST）の構築、およびスタックマシン向けの中間コード生成までの一連の流れを習得しました。
  • オブジェクト指向の習得: 大規模なコードを保守性高く設計するためのデザインパターンやクラス設計の基礎を実践しました。
Python 研究・データ分析

用途：研究支援ツール開発、統計処理、自動化

  • パケット生成・検証ツールの開発（約500行）: Scapy等のライブラリを活用し、研究対象のプロトコル変換をテストするためのパケット生成スクリプトを構築。
  • 統計処理・可視化: 実験結果（スループットや遅延）のログを解析し、MatplotlibやSeabornを用いたグラフ作成、および統計的な評価に活用しています。
